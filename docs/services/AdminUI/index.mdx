## Overview

### Normalization Testing

* **Operation Testing Interface**: Comprehensive testing dialog that allows administrators to validate normalization operations against sample FHIR resources before deployment.
* **Real-time Validation**: Immediate JSON validation with helpful error messages and resource type consistency checking.
* **Interactive Testing Workflow**: Three-panel interface showing original resource input, operation details, and transformed output side-by-side.
* **Resource Type Validation**: Automatic validation that ensures the selected resource type matches the FHIR resource being tested.

### Authentication

The Admin UI supports authentication using:

* OAuth2 via an identity provider (e.g., Azure AD, Keycloak), enabling secure login with centralized identity and access management.
* Token Generation via AdminBFF /api/login, which provides session tokens for downstream API access when deployed in a simplified or standalone context.
