## Overview

Contains facility and timing information used to initiate an on‑demand report generation process.

## Command Schema

### Key

```json
{

  "facilityId": "string"
}
```

### Headers

| Header Name               | Description                                                                                        |
|--------------------       |----------------------------------------------------------------------------------------------------|
| X-Exception-Facility-Id   | The consumer facility Id that experienced an error processing the event (when applicable)          |
| X-Exception-Message       | The consumer exception message when the event is sent to the 'error' topic                         |
| X-Retry-Exception-Message | The consumer exception message when the event is sent to the 'retry' topic                         |
| X-Retry-Count             | The retry attempts made by the consumimg 'retry' service                                           |
| X-Exception-Service       | The name of the service that produced the event to the 'error' or 'retry' topics                   |
