## Overview

The `ReportStatusUpdated` event is a centralized mechanism for tracking the granular progress of a report. It is produced by processing services (Data Acquisition, Measure Evaluation, Validation, Submission) and consumed by the [[service|ReportService]] to update the state of reports and patients.
