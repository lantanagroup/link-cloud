## Overview

Produced by [[service|MeasureEvalService]] after evaluating a patient against a measure. It includes metadata about the generated report and references to where the report is stored.

<NodeGraph />

## Event Schema

### Key

The facility ID (string) is used as the Kafka message key.

### Headers

| Header Name      | Description                                                                                        |
|------------------|----------------------------------------------------------------------------------------------------|
| X-Correlation-Id | The correlation ID associated with the event that should be used in logs produced during the event |
