## [Data Acquisition Worker Service - 0.6.0](https://lantanagroup.github.io/docs/services/DataAcquisitionWorkerService/0.6.0.mdx)

The Data Acquisition Worker is a .NET background service that listens on the ReadyToAcquire Kafka topic and processes queued data acquisition logs to fetch FHIR resources for a facility.

### Sends
- [Resource Acquired - 0.6.0](https://lantanagroup.github.io/docs/events/ResourceAcquired/0.6.0.mdx) - Represents a single FHIR resource retrieved from a facility.

### Receives
- [Ready to Acquire - 0.6.0](https://lantanagroup.github.io/docs/events/ReadyToAcquire/0.6.0.mdx) - Indicates when a data acquisition log is ready to be processed

- Does not write to any containers
