## Overview

Signals that a measure report for a patient has been produced and stored in blob storage within the given report directory.

<NodeGraph />

## Event Schema

### Key

None

### Headers

| Header Name      | Description                                                                                        |
|------------------|----------------------------------------------------------------------------------------------------|
| X-Correlation-Id | The correlation ID associated with the event that should be used in logs produced during the event |

### Payload

* FacilityId: string
* ReportTrackingId: string
* PatientId: string
* ReportType: string
* MeasureReportURI: string - The base URL of the report in blob storage
* MeasureReportFileName: string - The name of the file for the patient in the report directory

Example:

```
{
    "FacilityId": "123456789",
    "ReportTrackingId": "123456789",
    "PatientId": "12345",
    "ReportType": "Hypo",
    "MeasureReportURI": "https://storageaccount/container/report",
    "MeasureReportFileName": "patient-12345.json"
}
```
