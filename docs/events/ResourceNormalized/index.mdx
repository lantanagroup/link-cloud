## Overview

Produced after the resource is transformed according to configured mappings so evaluation components can work with a 
consistent format.

<NodeGraph />

## Event Schema

### Key

```json
{
  "tenantId": "string",
  "facilityId": "string"
}
```

### Headers

| Header Name                       | Description                                                                                        |
|--------------------               |----------------------------------------------------------------------------------------------------|
| X-Correlation-Id                  | The correlation ID associated with the event that should be used in logs produced during the event |
| kafka_orginal-offset              | The consumer facility Id that experienced an error processing the event (when applicable)          |
| kafka_dlt-original-consumer-group | The consumer exception message when the event is sent to the 'error' topic                         |
| kafka_original-topic              | Spring Boot generated header |
| kafka_original-timestamp          | Spring Boot generated header |
| kafka_original-partition          | Spring Boot generated header |
| kafka_exception-cause-fqcn        | Spring Boot generated header |
| kafka_exception-stacktrace        | Spring Boot generated header |
| kafka_exception-fqcn              | Spring Boot generated header |
| kafka_exception-message           | Spring Boot generated header |
| retry_topic-original-timestamp    | Spring Boot generated header |
| retry_topic-attempts              | Spring Boot generated header |
| retry_topic-backoff-timestamp     | Spring Boot generated header |
