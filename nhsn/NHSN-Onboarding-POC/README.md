# NHSN-Onboarding-POC

## Overview

This is a proof of concept of the NHSNLink facility on-boarding workflow.

## Launch

Node JS is required to run the application. Once installed, the following needs to be run from a terminal in the project directory:

`node server.js`

After running the command, access your browser and go to: `http://localhost:5173/` to access the application.
