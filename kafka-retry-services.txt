# topic:service[,service]
# kafka-topics-sync creates {topic}-Retry-{service} and {topic}-Redrive-{service}
# with at least the main topic partition count. It never deletes or shrinks.
# Prefix a service with ~ to create only {topic}-Redrive-{service}.
# Use that when the service subscribes to its redrive topic and has no retry consumer.
# Prefix a service with ! to create only {topic}-Retry-{service}.
# PayloadSubmitted uses that: redrives are published back onto the main topic.
